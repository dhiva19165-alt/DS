# Data Structures Lab Programs

This repository contains C implementations of various Data Structures concepts from lab experiments.

## Programs Included

| Experiment | File | Description |
|------------|------|-------------|
| Ex 1.A | `Ex_1A_Array_Implementation_of_List_ADT.c` | Array Implementation of List ADT |
| Ex 1.B | `Ex_1B_Implementation_of_Singly_Linked_List.c` | Singly Linked List |
| Ex 2 | `Ex_2_Implementation_of_Circular_Linked_List.c` | Circular Linked List |
| Ex 3.A | `Ex_3A_Array_Implementation_of_Stack.c` | Array Implementation of Stack |
| Ex 3.B | `Ex_3B_Array_implementation_of_Queue.c` | Array Implementation of Queue |
| Ex 4.A | `Ex_4A_Linked_List_Implementation_of_Stack.c` | Linked List Implementation of Stack |
| Ex 4.B | `Ex_4B_Linked_List_Implementation_of_Queue.c` | Linked List Implementation of Queue |
| Ex 5 | `Ex_5_Implementation_of_Binary_Search_Tree.c` | Binary Search Tree |
| Ex 6 | `Ex_6_Implementation_of_AVL_Tree.c` | AVL Tree |
| Ex 8 | `Ex_8_Applications_of_Graph.c` | Graph Applications (Dijkstra's Algorithm) |
| Ex 9 | `Ex_9_Implementation_of_Priority_Queue.c` | Priority Queue (Heap) |
| Ex 10.A | `Ex_10_A_Linear_Search.c` | Linear Search |
| Ex 10.B | `Ex_10_B_Binary_Search.c` | Binary Search |
| Ex 10.C | `Ex_10_C_Insertion_Sort.c` | Insertion Sort |

| Ex 12 | `Ex12_Student_Record_System.c` | Student Record System |

## How to Compile and Run

```bash
gcc -o program filename.c
./program
```

## Notes

- Some programs use menu-driven interfaces.
- Codes are extracted from lab PDF documents; minor OCR/layout artifacts may exist in a few files.
- Compile with a standard C compiler (gcc recommended).
